# Temnorid Arena identity

The game emblem is a flame inside a faceted diamond. It is distinct from the other Temnorid game marks.

- `logo.svg`: editable square logo, with an opaque background.
- `logo.png`: 1024 × 1024 PNG, ready to use as the source for a future game icon.
- `logo-mark.svg`: transparent, editable symbol without the tile.
- `favicon.svg`, `favicon.png`, `favicon.ico`: browser icons; the ICO contains 16, 32 and 48px versions.
- `apple-touch-icon.png`: 180 × 180 touch icon.
- `seo.png`: 1200 × 630 sharing image referenced by Open Graph and Twitter tags.

Keep the emblem square and preserve its clear space. The PNG is opaque; use the transparent SVG when placing the mark on another surface. Raster exports can be recreated from the SVG sources with CairoSVG and Pillow. No font is needed to render the symbol. The website uses the existing game palette; Unity Player Settings have not been changed.
