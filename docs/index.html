Spells instead of guns.

Temnorid Arena is a fast arena game for mages. Throw fireballs, freeze anyone who gets close, shield up and blink out of trouble. Play on PC, a phone or in VR on Meta Quest 3, all in the same matches.

What you do

Version 0.1 is an endless free-for-all deathmatch. You start a match, five bots join, and everyone fights everyone in a stone arena. Defeated mages come back three seconds later. Your kills and deaths are kept across matches.

Four spells, one mana bar

Every mage carries the same four spells. Each costs mana and has a cooldown, and mana refills on its own, so the fight is about timing, not loot.

One match, every device

PC, Android, iPhone and Meta Quest 3 players join the same games. In VR you cast along your hand; on a phone you get touch controls. The rules are the same for everyone.

Host it yourself

The player who presses Play vs bots hosts the match. Friends on the same network join by typing that player's address.

The spells

You have 100 health and 100 mana. Mana comes back at 12 per second. Pick a spell with 1–4 and cast it with the left mouse button.

Download

Version 0.1.0. All builds play together. Files come from the game's GitHub releases.

Windows PC

Zip, 65 MB · Windows 10 or later, 64-bit

  1. Unzip the folder anywhere.
  2. Run TemnoridArena.exe.
  3. If Windows SmartScreen warns, choose More info → Run anyway. The game is not signed yet.
Download for Windows

Android Phone

APK, 90 MB · 64-bit Android phone, landscape

  1. Open the file on your phone.
  2. Allow installing apps from this source when Android asks.
  3. Touch controls appear on their own.
Download APK

Meta Quest 3 VR

APK, 96 MB · installed from a computer (sideloading)

  1. Turn on Developer Mode for the headset in the Meta Horizon app.
  2. Connect it by USB-C and accept "Allow USB debugging".
  3. Run adb install -r TemnoridArena-0.1.0-quest.apk.
  4. On the headset: Library → Unknown Sources → Temnorid Arena.
Download Quest APK

iPhone and iPad Not in the App Store yet

Build it yourself on a Mac with Xcode

  1. Clone the game and open it in Unity 6000.6 with iOS Build Support.
  2. Temnorid → Build iOS Xcode Project.
  3. Open the project in Xcode, pick your team, run it on your device.
